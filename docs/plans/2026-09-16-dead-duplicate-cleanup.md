# ТЗ — убрать два мёртвых дубликата `_format_amocrm_counters` в `bot.py`

Дата: 2026-09-16
Исполнитель: mechanic (Sonnet)
Тип: механическая правка, проектных решений не требует
Решение владельца: 2026-09-16 — убрать лишние объявления.

## Зачем

В `bot.py` функция `_format_amocrm_counters` объявлена **три раза** с полностью
идентичным телом (проверено программно, строка в строку). Питон оставляет
последнее объявление, первые два — мёртвый код, след старого копипаста.
На поведение они не влияют, но путают при чтении и в карте функций.

## Факты на момент написания ТЗ

`bot.py` — 15014 строк. Три объявления, тело каждого 12 строк:

| Объявление | Строки | Судьба |
|---|---|---|
| Первое | 5572–5583 | **удалить** |
| Второе | 5598–5609 | **удалить** |
| Третье | 5650–5661 | **оставить** (именно оно и работает) |

Между первым и вторым стоит **чужая функция** `_last_birthday_date` (5586–5595) —
её не трогать. Между вторым и третьим тоже есть чужой код.

Номера строк даны на состояние `bot.py` в коммите `4e3b0dd`. Перед правкой
**проверить их заново** через `grep -nE "^def _format_amocrm_counters" bot.py` —
если номера разошлись, работать по фактическим.

## Задача 1. Удалить два объявления

Удалить первое и второе объявления целиком, вместе с отбивкой, так чтобы между
соседними функциями осталось **ровно две пустые строки** (как принято в файле).
Третье объявление остаётся нетронутым.

Проверка сразу после правки:

1. `grep -cE "^def _format_amocrm_counters" bot.py` — должно быть **1**.
2. `.venv-wahelp/bin/python -m py_compile bot.py` — без ошибок.
3. Файл стал короче ровно на 24 строки кода плюс снятая отбивка; фактическую
   длину зафиксировать (`wc -l bot.py`) — понадобится в задаче 2.
4. Тройных пустых строк не появилось: `grep -nE "^$" bot.py` в районе правки
   посмотреть глазами, либо проверить, что нет трёх пустых подряд.

## Задача 2. Обновить карту функций

Правка сдвигает номера строк для всего, что лежит **ниже** места удаления,
а карта `bot.py.map.md` только что перестроена и должна остаться правдивой.

Проще всего перестроить её тем же способом, что записан в её шапке:

```bash
grep -nE "^def |^class |^async def " bot.py
```

Требования:

1. Описания переносятся **дословно по имени** функции/класса, меняется только
   номер строки. Ни одно описание не переписывать.
2. Записи двух удалённых объявлений `_format_amocrm_counters` убрать. Должна
   остаться **одна** запись этой функции, с описанием без слов про дубликаты:
   `Форматирование счётчиков импорта amoCRM`.
3. Шапку обновить: актуальное число строк файла и актуальное число объявлений
   (станет 490). Дату оставить `2026-09-16`. Строку «Способ построения» не менять.
4. Формат таблицы и разметку не менять.
5. Проверка: число записей в карте равно `grep -cE "^def |^class |^async def " bot.py`;
   выборочно сверить **пять** записей ниже места правки через `sed -n '<N>p' bot.py` —
   на указанной строке должно стоять заявленное объявление.

- Не переписывать описания в карте.
- Не пушить: пуш решает владелец.
