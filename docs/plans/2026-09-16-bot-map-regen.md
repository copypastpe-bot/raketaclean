# ТЗ — перегенерация карты функций `bot.py`

Дата: 2026-09-16
Исполнитель: mechanic (Sonnet)
Тип: механическая работа, проектных решений не требует

## Зачем

`bot.py.map.md` — карта функций: по ней координатор и исполнители находят нужный
участок файла на 15 тысяч строк, не читая его целиком. Правки 16.09 сдвинули
номера строк, а поправлены были только затронутые записи. Сейчас карта врёт:
по её номерам можно открыть не то место.

## Что есть сейчас

- `bot.py` — 15014 строк, 492 объявления верхнего уровня.
- `bot.py.map.md` — 501 строка, 492 записи. Состав полный, номера строк частично устарели.
- Шапка карты говорит «строк: 15004» и «Дата: 2026-09-10» — тоже устарело.

## Задача 1. Перегенерировать карту

Построить карту заново по тому же способу, что записан в её шапке:

```bash
grep -nE "^def |^class |^async def " bot.py
```

Требования:

1. **Описания сохранить.** Они написаны раньше и проверены. Сопоставление —
   **по имени функции или класса**: если имя есть в старой карте, описание
   переносится дословно, меняется только номер строки.
2. **Новым объявлениям** (имя в `bot.py` есть, в старой карте нет) написать
   описание одной строкой — по имени и докстрингу. Файл целиком не читать:
   достаточно докстринга и нескольких строк тела.
3. **Исчезнувшие записи** (имя есть в карте, в `bot.py` нет) удалить.
4. **Порядок строк** — по возрастанию номера строки, как сейчас.
5. **Формат таблицы не менять**: `| Строка | Функция/класс | Назначение |`,
   классы пишутся как `` `class Имя` ``, функции — как `` `имя` ``.
6. **Шапку обновить**: дата `2026-09-16`, актуальное число строк файла,
   актуальное число объявлений. Строку «Способ построения» оставить как есть.

## Задача 2. Проверить результат

Перед тем как отчитаться, выполнить и убедиться:

1. Число записей в карте равно числу объявлений в файле:
   `grep -cE "^def |^class |^async def " bot.py` и `grep -cE "^\| [0-9]+ \|" bot.py.map.md`
   дают одно и то же число.
2. **Выборочная сверка десяти записей**, равномерно по файлу (первая, последняя
   и восемь между ними): по номеру строки из карты в `bot.py` действительно стоит
   объявление с этим именем. Проверять через `sed -n '<N>p' bot.py`.
3. Ни одно описание из старой карты не потеряно: имена, которые были и остались,
   имеют ровно тот же текст назначения.

## Задача 3. Коммит

Один коммит, только файл `bot.py.map.md`. Ничего другого в индекс не добавлять:
в репозитории идёт параллельная работа. Сообщение коммита — по-русски, по сути.

## Чего НЕ делать

- Не трогать `bot.py` — ни одной правки, даже косметической.
- Не переписывать описания, которые уже есть и подходят.
- Не менять формат карты и не добавлять новых колонок.
- Не создавать карт для других файлов.
- Не пушить: пуш решает владелец.

## Отчёт

Ответом вернуть: сколько записей стало, сколько описаний перенесено, сколько
написано заново, сколько удалено, результат выборочной сверки десяти записей,
SHA коммита.
