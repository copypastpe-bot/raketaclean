# Карта функций: adminbot/autocall/engine.py

Заведена 2026-10-23 (задача 2 ТЗ `docs/plans/2026-10-23-autocall-manager-button.md`:
кнопка «Я уже перезвонил» довела файл до 589 строк). Номера — по факту
`grep -nE '^(async )?def |^class |^    (async )?def '`.

Строк в файле: 614.

Движок автозвонка: исполняет решения машины попыток (`chain.py`) через хранилище,
АТС и амо. Три инварианта — в докстрине модуля: намерение до звонка, репетиция без
следов, неизвестный исход = неудача менеджера. С ТЗ 2026-10-23 — сообщение менеджеру
с кнопкой (одно на цепочку, правится) и остановка по нажатию перед повтором; всё это
только при выключателе `AUTOCALL_MANAGER_BUTTON`, без него поведение прежнее.
