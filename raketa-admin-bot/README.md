# raketa-admin-bot

Личный админ-бот владельца raketaclean: отдельный сервис на VPS, автоматизирующий административную работу, которую владелец делает руками. Не имеет отношения к рабочему боту сотрудников (он лежит в корне этого же репозитория) — только читает его базу.

## Функции

- **amo_sync (v1, в разработке)** — автоматическое проведение сделок в amoCRM по данным рабочего бота: поиск/создание сделки по телефону и дате, заполнение, проведение по этапам до «ЗАКАЗ ВЫПОЛНЕН и Оплата получена», закрытие автозадач; неоднозначные случаи — карточка-вопрос владельцу в Telegram; вечерняя сверка в 21:00 МСК.
- Планы: синхронизация с Google Calendar (этап 2), разбор Excel партнёра по коврам (этап 3), замена ручного CSV-импорта амо→бот (этап 4).

## Технологии

Python 3.11+, aiogram 3, asyncpg, aiohttp. Отдельный systemd-сервис на VPS (образец — деплой аналитики в `docs/analytics_deploy.md` в корне репозитория).

## Жёсткие правила

- В таблицы рабочего бота — только чтение; своё состояние — в отдельной схеме БД.
- Запись в amoCRM — только через выделенную интеграцию с правом записи.
- У каждой функции свой выключатель; по умолчанию выключено.
- ПД клиентов не попадают в git и логи; телефоны маскируются до последних 4 цифр.
