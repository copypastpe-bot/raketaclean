# Карта функций `cleaning/handlers.py`

2081 строка. Роутер aiogram со всеми диалогами клининга: проведение уборки,
касса, выплата прибыли, отмена. Подключается в `bot.py` через
`dp.include_router(cleaning_router)`.

Как читать: почти всё здесь — шаги пошаговых диалогов (FSM). Один диалог —
это цепочка «старт → вопрос → вопрос → подтверждение → проведение»; деньги
пишутся только на последнем шаге, внутри одной транзакции.

Осторожно: заглушка «команда не распознана» в `bot.py` ловит текст раньше
этого роутера, поэтому каждая новая текстовая кнопка бригадира не работает,
пока её не впишут в мост (известное ограничение, `AGENT_STATE.md`).
Внутри шага диалога (FSM) заглушка не мешает — у неё `StateFilter(None)`;
проверено через настоящий диспетчер в `tests/test_cleaning_olya_choice.py`.
Команды (текст с «/») заглушка не ловит вовсе — проверено для `/cleaning_olya`
в `tests/test_cleaning_olya_view.py`.

## Шаг «Оля / Дима» (из чьих денег операция)

Админские операции с кассой спрашивают, чьи деньги: «Оля» — деньги компании на
руках у Оли (`cash_holder='olya'`), «Дима» — обычная касса (`'dima'`). Шаг идёт
после суммы, до комментария (у выплаты — до подтверждения), в четырёх сценариях:
приход, изъятие, выплата прибыли и расход `/cleaning_expense`, если его ведёт не
клинер. Второй расход, `/cleaning_cash_expense`, удалён 05.10
(`docs/plans/2026-10-05-admin-menu.md`, задача 2). Тексты вопросов — константы
`CASH_HOLDER_QUESTION_SPEND` / `CASH_HOLDER_QUESTION_INCOME`. Строка «Деньги Ольга: N₽» в чат — только при «Оля».

| Строка | Функция | Назначение |

## Проведение уборки (`CleaningOrderFSM`)

Порядок шагов: телефон → имя → комментарий → сумма → бонусы → способ оплаты →
сумма оплаты → расходы → [только админ: «Оля / Дима»] → подтверждение → проведение.

Админ (роль admin/superadmin) проводит тем же сценарием; признак `by_admin` ставит
`start_cleaning_order`. Один ответ «Оля / Дима» решает: куда наличные и карта, откуда
расходы уборки и чья уборка — «Оля» → запись по `CLEANING_OLYA_FOREMAN_ID`, «Дима» → запись
самого админа (заводится при первой такой уборке). «Расчётный» — всегда «Дима». Путь Оли
не меняется (ТЗ `docs/plans/2026-10-30-admin-cleaning-order.md`).

## Удаление перемещения (`CleaningCashMoveDeleteFSM`)

По образцу `/cleaning_dividend_cancel` (ТЗ `docs/plans/2026-10-05-olya-money-move.md`,
задача 4). Удаление проверяется на шаге подтверждения
(`admin_ops.check_cash_move_delete`) и ещё раз под замком при «Провести»
(`admin_ops.delete_cash_move`). Номер больше `_PG_INT4_MAX` (id — integer)
до базы не доходит, ответ — «не найдено».
