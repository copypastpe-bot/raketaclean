## Purpose

Один репозиторий, три службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM и письма клиенту). `raketa-admin-bot/` — админ-бот только для владельца: amo_sync, ковры, два календаря, автозвонок, разбор удалённых заказов. `raketa-notify/` — служба оповещений (шина), на сервер ещё не поставлена. Базу рабочего бота админ-бот читает только на чтение, в amoCRM пишет своей интеграцией.

## Known Limitations

- **Ночная пауза считается по `Europe/Moscow` из системной базы часовых поясов** — на сервере нужен `tzdata` (в обычной Ubuntu/Debian есть).
- **Счётчик проходов и пометка о серой поломке живут в памяти процесса:** после перезапуска службы поломка подтверждается заново (три минуты), возможна одна повторная запись.
- **Уровень записи журнала переходник берёт из текста строки, а не из метки systemd** — предположение исполнителя, на живом journald не проверено.
- **Курсор журнала не переживает перезапуск службы**: после рестарта читается с текущего конца.
- **`notifications/outbox.py:626`** кладёт в журнал весь payload вебхука с телефоном клиента; защита — маскировка в переходнике.
- **rtk-обёртка врёт по pytest** («No tests collected» при прошедших тестах). Настоящий прогон — через `rtk proxy ... -m pytest`.
- **Тестовая база службы у координатора отдельная** (`notify_test_coord`): параллельные исполнители дерутся за пересоздание схемы в `notify_test`.
- **Папка `robot_amo` — боевой вход**: файл партнёра до 100 строк робот проведёт и заведёт сделки.
- **Файлы, положенные на сервер руками, ломают штатное обновление** (`git pull` не перезапишет untracked-файл).
- **Бутстрап схем создаёт таблицы с нуля, но не мигрирует существующие** — миграции накатывать руками ролью `bot` до рестарта.
- Прокси вне РФ — общая точка отказа трёх ботов; если он ляжет, служба не сообщит и о нём самом.
- Деплой ручной, SSH `admin@91.200.150.68`. Рабочий бот: `git pull --ff-only`, миграции руками, рестарт. Админ-бот — `rsync`, затем `sudo raketa-admin-bot-update`.
- Тесты: корень — `.venv-wahelp/bin/python -m pytest tests/ -q` с `raketaclean_test`; админ-бот — из его каталога с `adminbot_test`; служба — из `raketa-notify/` с `notify_test`.
