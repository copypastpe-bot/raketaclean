## Purpose

Один репозиторий, три службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM, письма клиенту). `raketa-admin-bot/` — админ-бот владельца: amo_sync, ковры, календари, автозвонок, цепочка заказа, оплата по счёту, отклики на промо, «Повторный заказ» по оценке. `raketa-notify/` — служба оповещений (шина), поэтапное включение. Базу рабочего бота админ-бот только читает, в amoCRM пишет своей интеграцией.

## Known Limitations

- **Перезапуск `telegram-bot`** — по слову владельца; `sudo -n systemctl restart telegram-bot.service` у агента работает. Состояния FSM живут в памяти — перезапуск их стирает (кнопки админа от этого защищены). nginx — только владелец.
- **Служба оповещений: код обновляет только владелец** (`sudo rsync` агенту закрыт), `raketa-notify/docs/runbook.md` §8.
- **Выключатели админ-бота** — в его `.env`, обёрткой `sudo raketa-admin-bot-update --<ключ>`; новые ключи — со второго запуска; после правки обёртки — `--report`. Миграции обёртка гоняет все — только идемпотентные.
- **Выключатели рабочего бота** — `/opt/telegram-bot/switches.env` (владелец `admin`), после перезапуска.
- **База на проде:** `psql -d clients_db` как `admin` (peer), чтение `public` и `adminbot`; запись в `adminbot` — только владелец. Миграции рабочего бота — от роли `bot` (`DB_DSN`, не печатать) и строкой в `public.schema_migrations` (последняя — 0017), порядок — `docs/deploy.md`.
- **Тесты:** админ-бот — `TEST_DB_DSN=postgresql://postgres@127.0.0.1:5432/adminbot_test .venv/bin/python -m pytest -q`; рабочий бот — `…/raketaclean_test .venv-wahelp/bin/python -m pytest tests/ -q`; служба — `raketa-notify/` с `notify_test`. Через `rtk` только `rtk proxy … -m pytest`. В `.venv-wahelp` поставлен `pyflakes` (проверка неопределённых имён после удалений).
- **Исполнителям:** запрет `stash`/`worktree`/`merge`/`push`; сверка HEAD первым шагом; одна задача на субагента; ревьюерам тесты запрещены; у механика потолок 80 ходов — давать ему ≤2 правки.
- **Деплой:** рабочий бот — `git pull --ff-only` в `/opt/telegram-bot` + миграции + перезапуск; админ-бот — `rsync` → `sudo raketa-admin-bot-update`. `sudo systemctl daemon-reload` агенту недоступен.
- Папка `robot_amo` — боевой вход ковров. Прокси вне РФ — общая точка отказа трёх ботов.
