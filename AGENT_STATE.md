## Purpose

Один репозиторий, две службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM и письма клиенту). Подпапка `raketa-admin-bot/` — админ-бот только для владельца: amo_sync (химчистка и уборки), carpets (Excel партнёра), gcal (два календаря), autocall (звонок по заявке с сайта). Базу рабочего бота админ-бот читает только на чтение (учётка `adminbot` имеет лишь SELECT), в amoCRM пишет своей интеграцией.

## Known Limitations

- **Папка `robot_amo` — боевой вход**: фильтр почты кладёт туда любое письмо партнёра. Защита ловит файлы больше 100 строк и неразобранные; файл до 100 строк с новыми заказами робот проведёт и заведёт сделки с нуля (по замыслу). Перед запросом файлов у партнёра всё равно предупреждать. Матчер берёт единственную открытую ковровую сделку клиента без учёта дат.
- 4 старые записи `carpet_letters` с порядковыми номерами 1–4 остались (письма прочитаны, строки проведены); практических последствий нет.
- API amoCRM v4 сделки не удаляет: лишнее удаляет владелец руками, робот только закрывает.
- **`recon/data/` и xlsx в корне содержат ПД и в git не попадают** (`.gitignore`).
- `fetch_contact_leads` с фильтром `filter[contacts][id]` amoCRM молча игнорирует; поиск контакта по телефону — подстрочный `query` без пагинации.
- Проход отмен читает карточку каждого свежего ожидания раз в 10 минут: десятки запросов в CRM за проход.
- Прокси вне РФ — общая точка отказа трёх ботов; на VPS DNS для `api.telegram.org` отдаёт только нероутируемый IPv6.
- Деплой ручной, SSH `admin@91.200.150.68`; NOPASSWD покрывает обе службы и `raketa-admin-bot-update` со всеми ключами, но не `sudo -u adminbot psql` и не правки системы. Админ-бот — два шага: rsync в `/home/admin/raketa-admin-bot`, затем `sudo raketa-admin-bot-update`; один `update` без rsync поднимает старую версию (так было 15.09). Новый ключ скрипта работает со второго вызова.
- Переделки по гарантии робот не различает; суточный лимит отправок 60 на компанию; клининг: «Расчётный» зачисляет в кассу сразу, живых уборок 4.
