## Purpose

Один репозиторий, две службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM и письма клиенту). Подпапка `raketa-admin-bot/` — админ-бот только для владельца: amo_sync (химчистка и уборки), carpets (Excel партнёра), gcal (два календаря), autocall (звонок по заявке с сайта). Базу рабочего бота админ-бот читает только на чтение (учётка `adminbot` имеет лишь SELECT), в amoCRM пишет своей интеграцией.

## Known Limitations

- **Папка `robot_amo` — боевой вход**: файл партнёра до 100 строк робот проведёт и заведёт сделки с нуля. Перед запросом файлов предупреждать. Матчер берёт единственную открытую ковровую сделку клиента без учёта дат.
- **Переотправка клиенту вторым каналом идёт медленно**: по одному сообщению старше 10 минут, пауза 1–60 минут (решение владельца 16.09 — оставить).
- **Сообщения менеджеру по автозвонку идут без страховки**: токеном рабочего бота в личку, при обрыве теряются.
- **Заглушка `unknown` в `bot.py`** ловит текст раньше `cleaning_router`: каждая новая кнопка бригадира ломается, пока её не впишут в мост `cleaner_button_bridge`. В парке до появления новых кнопок (решение владельца 16.09).
- Репетиция уборок не проходит путь «новый клиент» до конца: он ждёт автосделку сейлзбота, которой в репетиции нет.
- API amoCRM v4 сделки не удаляет: лишнее удаляет владелец руками, робот только закрывает.
- `recon/data/` и xlsx в корне содержат ПД и в git не попадают.
- Прокси вне РФ — общая точка отказа трёх ботов; резервные DNS с 15.09.
- Деплой ручной, SSH `admin@91.200.150.68`. Рабочий бот: `git pull --ff-only` в `/opt/telegram-bot` плюс рестарт. Админ-бот — два шага: `rsync`, затем `sudo raketa-admin-bot-update`; один `update` без `rsync` поднимает старую версию. NOPASSWD не покрывает `sudo -u adminbot`.
- Переделки по гарантии робот не различает; суточный лимит отправок 60 на компанию; клининг: «Расчётный» зачисляет в кассу сразу.
- Тесты: корень — `.venv-wahelp/bin/python -m pytest tests/ -q` (322); админ-бот — обязательно из его каталога: `cd raketa-admin-bot && TEST_DB_DSN=postgresql://postgres@127.0.0.1:5432/adminbot_test .venv/bin/python -m pytest -q` (872 плюс 9 пропущено).
