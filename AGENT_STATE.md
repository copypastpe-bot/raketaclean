## Purpose

Один репозиторий, три службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM, письма клиенту). `raketa-admin-bot/` — админ-бот владельца: amo_sync, ковры, календари, автозвонок, цепочка заказа, оплата по счёту, отклики на промо, «Повторный заказ» по оценке. `raketa-notify/` — служба оповещений (шина), поэтапное включение. Базу рабочего бота админ-бот только читает, в amoCRM пишет своей интеграцией.

## Known Limitations

- **Перезапуск `telegram-bot` — только владелец** (`sudo` с паролем; у агента `sudo -n` есть для `raketa-admin-bot-update`, не для `systemctl`). То же — nginx.
- **Служба оповещений: код обновляет только владелец** (`sudo rsync` агенту закрыт), команда — `raketa-notify/docs/runbook.md` §8.
- **Выключатели админ-бота** — в его `.env`, только обёрткой `sudo raketa-admin-bot-update --<ключ>`; обёртка обновляет себя — новые ключи со второго запуска; после правки обёртки — `--report`. Миграции обёртка гоняет все на каждом выкате — только идемпотентные.
- **Выключатели рабочего бота** — `/opt/telegram-bot/switches.env` (владелец `admin`, правится без sudo), действуют после перезапуска.
- **База на проде:** `psql -d clients_db` как `admin` (peer), чтение `public` и `adminbot`; запись в `adminbot` — только владелец (`sudo -u postgres`). Миграции рабочего бота — от роли `bot` (`DB_DSN` из `.env`, значение не печатать) и сразу строкой в `public.schema_migrations` (ведётся с 30.09, 0000–0016 записаны; порядок — `docs/deploy.md` «Миграции и их журнал»).
- **Тесты:** админ-бот — `TEST_DB_DSN=postgresql://postgres@127.0.0.1:5432/adminbot_test .venv/bin/python -m pytest -q`; рабочий бот — `…/raketaclean_test .venv-wahelp/bin/python -m pytest tests/ -q`; служба — `raketa-notify/` с `notify_test`. Через `rtk` только `rtk proxy … -m pytest`.
- **Исполнителям:** запрет `stash`/`worktree`/`merge`/`push` писать в промпт явно; сверка HEAD первым шагом; одна задача на субагента.
- **Деплой:** рабочий бот — `git pull --ff-only` в `/opt/telegram-bot` + перезапуск владельцем; админ-бот — `rsync` → `sudo raketa-admin-bot-update`. `sudo systemctl daemon-reload` агенту недоступен.
- Папка `robot_amo` — боевой вход ковров. Прокси вне РФ — общая точка отказа трёх ботов.
