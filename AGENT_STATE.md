## Purpose

Один репозиторий, три службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM и письма клиенту). `raketa-admin-bot/` — админ-бот только для владельца: amo_sync, ковры, два календаря, автозвонок, разбор удалённых заказов. `raketa-notify/` — служба оповещений (шина), установлена 21.09, идёт поэтапное включение. Базу рабочего бота админ-бот читает только на чтение, в amoCRM пишет своей интеграцией.

## Known Limitations

- **Шина знает один вид события.** В `notify.routes` только `notify.journal` → технический журнал. Клиентом `notify_bus` пока пользуются лишь тесты: сводки и алерты идут старыми дорогами.
- **Таймер ожидания автосделки не срабатывает никогда:** отсчёт от `updated_at`, который сам же обновляется каждую минуту. Запись висит в `waiting_salesbot` с 20.09, владельцу не сообщено. Задача 8 брифа.
- **Пустые категории хвостов печатаются нулями** — отложено до переезда на шину, решение владельца.
- **Тестам админ-бота нужен `TEST_DB_DSN`**, иначе 835 passed / 85 skipped вместо 962/9 — и прогон выглядит зелёным. Способ запуска записан в ТЗ сверки.
- **`rtk`-обёртка врёт по pytest**; настоящий прогон — через `rtk proxy ... -m pytest`.
- **Правила проекта живут в двух местах**: `CLAUDE.md` (для Claude) и `AGENTS.md` (для Codex, заведены 21.09). Менять надо оба, иначе агенты разойдутся в правилах.
- **Папка `robot_amo` — боевой вход**: файл партнёра до 100 строк робот проведёт и заведёт сделки.
- Прокси вне РФ — общая точка отказа трёх ботов; если он ляжет, служба не сообщит и о нём самом.
- **Деплой ручной, SSH `admin@91.200.150.68`.** Рабочий бот: `git pull --ff-only` в `/opt/telegram-bot`, рестарт. Админ-бот: `rsync` из `~/Projects/raketaclean/raketa-admin-bot/`, затем `sudo raketa-admin-bot-update` — оба шага обязательны. Служба: `git pull` в `/opt/telegram-bot`, затем `rsync` в `/opt/raketa-notify/app`.
- **`sudo systemctl daemon-reload` агенту недоступен** — нужен владелец. Рестарты трёх служб и `tee`/`mkdir` разрешены без пароля.
- Тесты: корень — `.venv-wahelp/bin/python -m pytest tests/ -q` с `raketaclean_test`; админ-бот — из его каталога с `TEST_DB_DSN`; служба — из `raketa-notify/` с `notify_test`.
