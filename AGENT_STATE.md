## Purpose

Один репозиторий, три службы. Корень — рабочий бот клининговой компании (заказы, лояльность, зарплата, касса, уведомления, админка, обмен с amoCRM и письма клиенту). `raketa-admin-bot/` — админ-бот только для владельца: amo_sync, ковры, два календаря, автозвонок, разбор удалённых заказов. `raketa-notify/` — служба оповещений (шина), **установлена 21.09**, идёт поэтапное включение. Базу рабочего бота админ-бот читает только на чтение, в amoCRM пишет своей интеграцией.

## Known Limitations

- **Ящик копится, пока идёт репетиция.** Включение боевой доставки отправит накопленное одним залпом.
- **Каталог `/opt/raketa-notify` принадлежит root**, поэтому `sed -i` по `switches.env` не работает — правка через временный файл в `/tmp`.
- `sudo` на сервере требует пароль для всего, кроме списка NOPASSWD: службы ботов, nginx, certbot и `raketa-notify.service`. Чтение `/opt/raketa-notify/.env` агенту недоступно — так и задумано.
- **Ночная пауза считается по `Europe/Moscow`** из системной базы часовых поясов; на сервере нужен `tzdata`.
- **Счётчик проходов и пометка о серой поломке живут в памяти процесса:** после перезапуска службы поломка подтверждается заново (три минуты).
- **Уровень записи журнала переходник берёт из текста строки**, а не из метки systemd — на живом journald не проверено.
- **Курсор журнала не переживает перезапуск службы**: после рестарта читается с текущего конца.
- **`notifications/outbox.py:626`** кладёт в журнал весь payload вебхука с телефоном клиента; защита — маскировка в переходнике.
- **rtk-обёртка врёт по pytest**; настоящий прогон — через `rtk proxy ... -m pytest`.
- **Тестовая база службы у координатора отдельная** (`notify_test_coord`): параллельные исполнители дерутся за схему в `notify_test`.
- **Папка `robot_amo` — боевой вход**: файл партнёра до 100 строк робот проведёт и заведёт сделки.
- **Бутстрап схем создаёт таблицы с нуля, но не мигрирует существующие** — миграции накатывать ролью `bot` до рестарта.
- Прокси вне РФ — общая точка отказа трёх ботов; если он ляжет, служба не сообщит и о нём самом.
